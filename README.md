# Express Blog Intro

Primo server Express per un blog: serve file statici e due rotte (`/` e `/bacheca`) che restituiscono un elenco di post (ricette) in JSON.

## Tecnologie

- Node.js
- Express 5
- JavaScript

## Avvio

```bash
npm install
npm start
# oppure in sviluppo
npm run dev
```

Server su `http://localhost:3000`.
